# Проверочная речь

`speech-check.wav` — синтетическая русская речь, созданная встроенным голосом
macOS Milena. PCM16, mono, 16 kHz. Пользовательских записей здесь нет.

Текст: «Это проверка локальной записи. Сегодня хорошая погода.
Мы проверяем звук и текст».

Установщик проверяет распознавание слов и таймкоды с запрещённым сетевым доступом.
Контрольная сумма файла закреплена в `../whisperx-models.json`.
