# Временно на этапе разработки

Только для локальной версии; код функций сохранён.

| Функция | Сейчас |
|---|---|
| Диаризация | Выключена в backend: `diarization_model: "none"`; один спикер. Для возврата — `pyannote/speaker-diarization-community-1`. |
| Запись микрофоном телефона | Нижняя кнопка `+` серая и неактивная, включая долгое нажатие. |
| Автозапуск CV1 | Запись начинается вручную; подключение устройства само её не запускает. |
| Live-транскрипт | Пока не подключён; распознаётся завершённый WAV. Переход с карточки записи отключён. |
| Автономная запись с последующей загрузкой | Пока не подключена к локальному сценарию. |
| Онлайн-функции | В локальном режиме отключены в целом. |

До появления live-экрана: **▶ Начать → ■ Остановить → Мьют** на карточке CV1.
Мьют доступен только внутри записи; остановка завершает WAV для автообработки.
Удаление временного UI: `TemporaryRecordingControls` и места использования
`TemporaryCaptureControls` (включая временную границу сессии в capture controller).
