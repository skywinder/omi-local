# Omi Local Next v0.2.0

This source release improves recording recovery, CV1 archive import, and troubleshooting on a self-hosted server.

- **Recording and Live.** The app keeps the recording intent through interruptions and reconnects to the selected input. The recording button shows elapsed time, and Live distinguishes audio saved on the phone from text returned by the server.
- **CV1 archive.** Full sync shows transfer speed, estimated time remaining, and the original dates of saved audio. Compatible firmware can confirm an archive advance after the phone saves the window. Legacy firmware still supports manual import and can have gaps after a Bluetooth interruption.
- **Speech detection.** Next can filter new audio with a phone-side speech detector when enabled for the pairing. Uncertain drafts stay on the phone for retry. CV1 auto-start is also opt-in.
- **Server and summaries.** The mobile server list shows service health for the connected server. The web library can fill in missing summaries on demand or on a schedule when enabled, preserving existing summaries.

The release identifies repository source. The app's package version and build number continue to follow the pinned Flutter package.
