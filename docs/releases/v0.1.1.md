# Omi Local Next v0.1.1

Omi Local now defaults to English across the mobile interface, web library, and server messages.

- **iPhone and Android.** Next opens in English on first launch, regardless of the phone language. Use **App Language** on the server pairing or management screen to save another language. The original Local app also defaults to English and honors its saved preference.
- **Web library.** The Live monitor, stream status, speaker labels, event times, transcript search results, folder actions, and deletion messages use English.
- **Server and setup.** Provider settings, connection checks, transcription setup, archive errors, and iPhone installation prompts use English. New recordings without a title receive an English default. Recordings and transcripts keep their original language.
- **Documentation.** The feature comparison, screenshots, and v0.1.0 release notes are available in English. English is the primary language for future releases and product descriptions.
