# Omi Local Next v0.1.0

Next is the primary Omi Local client for iPhone and Android. Both phones can record at the same time on one self-hosted server. Open either recording from either phone or the web library.

## Recording and Live

- **Phone microphone and Omi CV1.** Start, stop, or mute recording in the app. The CV1 supports button controls, recording on connection, and ending one conversation while continuing to listen. A manual stop persists across reconnects.
- **Interrupted uploads.** The phone keeps each audio part until the server confirms storage. The queue explains delays and supports retries. The server assembles parts in order, can split conversations at silence, and retains the original WAV.
- **Live transcripts.** Follow draft and confirmed text with timestamps, speaker labels, and optional translation. Adjust buffering and speaker count. The web monitor shows which phones are connected and which inputs are delivering audio frames.
- **CV1 diagnostics and recovery.** Check battery, signal strength, transfer rate, and connection history. Compatible firmware supports gain adjustment and a microphone test. Import one clip, a batch, or the available device archive and resume after a Bluetooth interruption. Recovery coverage depends on the firmware.

## Archive and playback

- **Keyword and semantic search.** Search titles, summaries, and transcripts. Open a matching passage at its timestamp. Semantic search uses a local index and requires setup.
- **Playback and transcript editing.** Play from a passage, find text within a recording, adjust speed, skip ten seconds in either direction, edit turns, and name speakers. WAV range requests support seeking near the end of long recordings.
- **Library and offline access.** Organize recordings with folders, emoji categories, favorites, archive, and restore. Filter by duration, available audio, or a no-speech result. Recent cards are available offline. Download selected recordings with full transcripts and audio within a shared 1 GiB phone limit. Export WAV or TXT.
- **Pending and duplicate audio.** The web library shows when the server is waiting for parts and offers a retry if a recording fails to open. Grouped recordings with byte-identical WAVs retain separate transcripts. Deleting one preserves the other.

## Summaries, chat, and tasks

- **Summaries and notes.** Choose a template and model, then regenerate a summary after editing the transcript. Web and Next share a background queue. The previous summary stays available until its replacement is ready. New summaries identify their template and model. Notes and action items can link to source passages.
- **Chat and memory.** Ask about a recording or the entire archive, keep separate chat histories, and open the sources behind an answer. Review, edit, accept, or reject suggested facts alongside their quotes. A change to the source sends the fact back for review.
- **Tasks and goals.** Create, edit, complete, or reopen tasks. Accept suggested action items and set local phone reminders. Track goal progress with recording links, pause a goal, resume it, or mark it complete.
- **Daily recaps.** Generate a recap for a date and follow its recording links. Enable scheduled recaps by choosing a time and time zone. The server runs the schedule while the app is closed.

## Server and access

- Run on a Mac or in Docker on CPU or NVIDIA GPU. Pair over Tailscale or an authenticated ngrok tunnel. Save and switch between multiple servers in Next.
- Configure live transcription, final transcription, diarization, and summaries independently. Options include WhisperLiveKit, WhisperKit, WhisperX, Parakeet, and compatible servers, depending on the stage. Supported generation screens identify the provider that will receive the text.
- Give an assistant read-only archive access with a separate MCP key. It can list and search recordings, read transcripts, and cite a specific source revision. [MCP setup](../../tools/archive-mcp/README.md)

## Fixes

- iPhone restores normal playback routing after microphone capture so audio plays through the speaker or connected output.
- Creating the provider registry on a Mac preserves an enabled local Parakeet Live profile and an explicitly disabled Live setting.
- Imported recordings show the full WAV duration, including trailing silence. Speech boundaries are tracked separately. The archive stays accessible during paired server startup, and recording memory loads its provider settings.

## Device verification

A physical iPhone and Android phone opened the archive, streamed audio simultaneously, and displayed Live text. In an early run, the recognizer returned text but did not acknowledge the end of the stream. Across three repeat runs, all six streams received that acknowledgment. All six recordings opened with audio, and the server confirmed all 19 parts. Long recordings with the screen locked still need a separate endurance test.

## Install from source
