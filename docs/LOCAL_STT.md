# Распознавание записей

Текст создаётся на Mac после окончания записи. Спорные места можно прослушать
по таймкоду в `omiloc`.

Запустите `start.command`, затем один раз выполните из папки проекта:

```bash
bash scripts/install-local-stt.sh
bash scripts/local-mac.sh auto-transcribe-on
```

Первая команда устанавливает WhisperX и скачивает около 3 ГБ моделей для русского
языка, без разделения говорящих. Нужны интернет, macOS 14 или новее и минимум
8 ГБ свободного места. Аккаунт Hugging Face для этого профиля не нужен.
Готовность проверяется на синтетической речи с таймкодами и запретом сети.

Если подготовка прервётся, повторите первую команду: проверенные файлы сохранятся,
недокачанные продолжат загружаться. Подробности — `.local/stt/install.log`.
Окружение и модели находятся в `.local/stt/` внутри проекта; домашние ML-окружения
и настройки другой модели установщик не меняет.

Новые записи будут обрабатываться автоматически. Текст появится в аудиотеке;
на iPhone обновите список и откройте «Локальная запись». Mac должен работать и не спать.
Записи, существовавшие до первого включения обработки, нужно передать вручную.

| Действие | Команда из папки проекта |
|---|---|
| Проверить обработку | `bash scripts/local-mac.sh transcription-status` |
| Выключить, сохранив записи | `bash scripts/local-mac.sh auto-transcribe-off` |
| Обработать файл или повторить после ошибки | `bash scripts/local-mac.sh transcribe "/путь/к/записи.wav"` |

Подходит WAV PCM16, mono, 16 kHz. Повтор с тем же файлом и настройками использует
сохранённый результат. После перезагрузки Mac снова запустите `start.command`.

## Выбор модели

Файл настроек — `.local/dev-harness/ngrok/stt-engine.json`.
Пример для WhisperX с русским языком и одним говорящим:

```json
{
  "engine": "whisperx",
  "model": "large-v3-turbo",
  "language": "ru",
  "diarization_model": "none"
}
```

Новые настройки применяются к новым задачам; уже начатые сохраняют прежние.
Для другой модели WhisperX измените `model`. Переустанавливать приложение не нужно.

WhisperX использует процессор Mac; Parakeet — графический процессор Apple Silicon.
Установщик готовит профиль из примера. Для другой модели или разделения говорящих
подготовьте отдельное окружение с моделями и задайте путь к его Python полем `python`.
Обработчик не скачивает модели во время записи.

`diarization_model: "none"` относит весь текст к одному говорящему.
Для разделения используется `pyannote/speaker-diarization-community-1`;
его подготовка не входит в стандартную установку. В старых ручных окружениях
без этого параметра разделение включено по умолчанию.
