# omiloc на Mac

Откройте **start.command** двойным щелчком — он работает в Terminal. Или выполните
из папки проекта:

```bash
./start.command
```

При первом запуске скрипт проверяет Mac и файлы проекта, устанавливает недостающие
зависимости, спрашивает HTTPS-адрес и authtoken ngrok, запускает локальные сервисы
и открывает аудиотеку. Нужны Mac с Apple Silicon и интернет для первой установки.
Если macOS не разрешает открыть загруженный файл, выполните `bash start.command`
в Terminal из папки проекта.

**Домен и ключ для iPhone показаны в рамке.** Введите их в разделе «Локальный Mac»
установленного приложения. Authtoken ngrok и ключ приложения — разные вещи.
Authtoken вводится скрыто; Enter переиспользует существующую настройку ngrok.
Домен и authtoken можно получить в [личном кабинете ngrok](https://dashboard.ngrok.com).

Ключ приложения показывается один раз. На Mac хранится только его проверочный хеш.
При повторном запуске ключ не меняется: используйте уже сохранённый в iPhone.
Если ключ потерян, остановите сервисы и выполните `bash scripts/local-mac.sh rotate-key`,
затем запустите скрипт снова и введите новый ключ в телефон.

## Аудиотека

Обычный адрес — [127.0.0.1:20001](http://127.0.0.1:20001). Страница доступна только
на этом Mac. Она читает завершённые локальные WAV и существующие результаты
распознавания; сервисы ngrok и iPhone для прослушивания архива не нужны.
После настройки команду можно выполнить из любой папки:

```bash
omiloc
```

Она запускает аудиотеку и открывает браузер. Уже работающий сервер используется
повторно. Команда устанавливается через `start.command` в `~/.local/bin` без sudo;
если Terminal ещё не видит её, откройте новое окно. Для уже подготовленного проекта
достаточно один раз выполнить `./omiloc --install` из его папки.

Для новых записей и удаления связанных разговоров запустите сервисы через
`start.command`; `omiloc` запускает только аудиотеку.

Выберите запись слева. Можно слушать весь файл, перематывать, менять скорость
и нажимать на фразы транскрипта, чтобы перейти к их таймкодам. Текущая фраза
подсвечивается. Список и готовые транскрипты обновляются автоматически.
Поиск работает по дате, источнику и началу транскрипта.

**Удалить запись** удаляет WAV, метаданные, все результаты распознавания этого аудио
и связанные локальные разговоры в приложении. Перед удалением есть подтверждение.
Во время распознавания удаление блокируется; дождитесь завершения и повторите.
Если есть вторая запись с абсолютно тем же WAV, общий транскрипт и разговор
сохраняются, пока не удалена последняя копия. Другие записи не затрагиваются.

После удаления **потяните список разговоров вниз на iPhone**. Для корректного
удаления последней записи нужна версия приложения с исправлением пустого списка
от 8 сентября 2026 года. Уже открытая карточка и офлайн-кеш обновляются после
успешного запроса; удаление с Mac не отправляет push-команду на телефон.

## Распознавание и приложение

Скрипт сохраняет существующую модель и настройку автообработки. Если обработчик
включён, он запускается вместе с сервисами. Подготовка ML-окружения и моделей
описана в [LOCAL_STT.md](LOCAL_STT.md); скрипт не скачивает модели автоматически.
Неподготовленная модель не мешает прослушивать уже записанный архив.

iOS-приложение устанавливается отдельно: нужны Xcode, Apple Development identity
и физический iPhone. `start.command` не собирает и не переустанавливает приложение.
См. [LOCAL_SETUP.md](LOCAL_SETUP.md).

## Остановка и диагностика

Терминал после успешного запуска можно закрыть. После перезагрузки Mac запустите
`start.command` снова. Для остановки собственных сервисов с сохранением данных:

```bash
bash scripts/local-mac.sh down
```

`./start.command --check` только проверяет готовность, ничего не устанавливает
и не показывает секретов. При ошибке скрипт останавливается на текущем шаге.
Подробная диагностика: `bash scripts/local-mac.sh check` и
`bash scripts/local-mac.sh status`. Чужие процессы и занятые ими порты не трогаются.
Если нужна подготовка зависимостей с полным выводом: `bash scripts/local-mac.sh install`.

Проверены повторный запуск на текущем Mac и отдельные проверки нового сценария.
Полная установка на втором чистом Mac ещё не проверена.
