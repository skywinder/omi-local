# Приложение на iPhone

Для записи нужен отдельно установленный локальный вариант Omi.
`start.command` готовит сервисы на Mac, но не устанавливает приложение на телефон.
После установки подключите его по [инструкции ngrok](NGROK.md).

## Требования к сборке

Этот раздел предназначен для человека, который устанавливает приложение.
Нужны Mac с Apple Silicon, Xcode, Apple Development identity, Flutter и CocoaPods,
а также физический iPhone с Developer Mode и USB-кабелем для передачи данных.
Проверены Xcode 26.6, Flutter 3.44.5, CocoaPods 1.16.2, iOS 26.6 и iPhone 17 Pro.
Существующий iOS-скрипт ограничен этой моделью телефона.

`app/setup.sh ios personal` объединяет подготовку, сборку, установку и запуск.
Для повторной установки уже готовой версии этот скрипт не нужен.

Для первой сборки задаются локальные `OMI_DEV_HOST` и `OMI_APPLE_TEAM_ID`,
при необходимости — `OMI_PERSONAL_BUNDLE_ID`. Поддерживается сочетание
`dev + local_dev + offline`, конфигурация `Profile-dev-iphoneos`.
Ключи, сертификаты и настройки подписи не входят в репозиторий.

Если код приложения, зависимости, инструменты и параметры подписи не менялись,
используйте уже проверенную сборку. Изменение сервера, сбой USB или смена адреса
ngrok сами по себе не требуют пересборки.

Перед установкой проверьте версию исходников, конфигурацию, SHA-256 исполняемого
файла, подпись и разрешения приложения. Точный путь готового приложения:

```text
app/build/ios/Profile-dev-iphoneos/Runner.app
```

Копия в `app/build/ios/iphoneos/Runner.app` может относиться к другой сборке.
Новая копия проекта не содержит готового приложения. Очистка перед сборкой нужна
только при изменениях подписи, нативных зависимостей или инструментов, либо при
подтверждённой проблеме с промежуточными файлами.

## Прежний режим локальной сети

Обычное подключение использует ngrok. LAN-режим сохранён для разработки в
доверенной сети: телефон и Mac должны находиться в одной сети, передача идёт без TLS.
Адрес Mac в `OMI_DEV_HOST` должен совпадать с адресом в сборке приложения.

[Команды LAN-режима и проверки](DEVELOPMENT.md#локальная-сеть) ·
